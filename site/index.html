Canapé

Regardez un film à deux, chacun chez vous, en vous voyant et en vous entendant. Une image nette, le son du film et vos voix en même temps.

Sur Ubuntu 24.04 :

curl -fsSL https://mawena.github.io/Canape/installer.sh | sh

Le script ajoute le dépôt APT signé puis installe le paquet ; une fenêtre de mot de passe s'ouvre pour les droits administrateur. Les trois commandes qu'il lance sont détaillées plus bas, pour qui préfère les taper soi-même.

Pourquoi pas Meet ?

Partager l'écran dans une visioconférence, c'est filmer son film, le compresser, puis le renvoyer en direct. Deux défauts en sortent, et Canapé les supprime tous les deux.

Le film n'est pas partagé, il est lu deux fois

Le film reste sur le serveur et chaque navigateur le lit lui-même, directement. Pas de partage d'écran : l'image est aussi nette chez l'un que chez l'autre, sans saccades.

Le film et la voix en même temps

Une visioconférence ne laisse passer qu'une source de son : le film ou le micro. Ici le son du film sort chez chacun, et les micros ne servent qu'à la conversation.

Une seule télécommande

Lecture, pause, déplacement dans le film et choix du film sont partagés : ce que fait l'un arrive chez l'autre, à moins d'une demi-seconde. Si l'un charge, le salon attend.

Installer

Pour Ubuntu 24.04 et les distributions Debian équivalentes. Une fois le dépôt ajouté, sudo apt update && sudo apt upgrade apporte les nouvelles versions.

  1. Ajouter la clé qui signe le dépôt :

    sudo curl -fsSLo /usr/share/keyrings/canape.gpg https://mawena.github.io/Canape/apt/canape.gpg

  2. Ajouter le dépôt :

    sudo curl -fsSLo /etc/apt/sources.list.d/canape.sources https://mawena.github.io/Canape/apt/canape.sources

  3. Installer :

    sudo apt update && sudo apt install canape
    • Le service canape démarre tout seul ; ffmpeg est recommandé (il sert à vérifier les films et à les convertir).

Sans le dépôt : téléchargez le paquet .deb et sa somme de contrôle sur la page de la dernière version, puis sudo apt install ./canape_*_all.deb.

Premiers pas

  1. Lire le mot de passe commun, créé à l'installation :

    sudo cat /etc/canape/secrets.conf
    • Pour le changer, modifiez CANAPE_MOT_DE_PASSE dans ce fichier, puis sudo systemctl restart canape.

  2. Ajouter des films dans /var/lib/canape/films. Pour y copier sans droits administrateur, ajoutez-vous au groupe du service (puis reconnectez-vous) :

    sudo adduser "$USER" canape
    • Sous-titres : un fichier .srt ou .vtt à côté du film, même nom (Film.fr.srt).
    • Un film marqué « à convertir » ? canape-convertir Film.mkv en fait un MP4 que tous les navigateurs lisent.

  3. Ouvrir http://localhost:8080, entrer le mot de passe et un prénom, choisir un film. Chacun fait de même de son côté.

  4. Pour que votre correspondant se connecte de chez lui, mettez le service derrière HTTPS : la caméra et le micro refusent de s'ouvrir sans cela (sauf sur localhost). Le plus simple est Caddy, qui obtient le certificat tout seul :

    canape.exemple.fr {
    reverse_proxy 127.0.0.1:8080
}
    • Dans /etc/canape/canape.conf : CANAPE_DERRIERE_PROXY=1 et CANAPE_HOTE=127.0.0.1, puis sudo systemctl restart canape.

Quand l'appel ne passe pas

Les caméras se parlent directement d'un navigateur à l'autre. Sur un réseau d'entreprise ou un pare-feu strict, il faut parfois un relais TURN : installez coturn, puis renseignez CANAPE_TURN_URLS et CANAPE_TURN_SECRET dans /etc/canape/canape.conf.

Avec un casque

Sans casque, le son du film qui sort des enceintes repart dans le micro. Un casque évite l'écho.

Sur téléphone aussi

Chrome, Firefox et Edge récents sur ordinateur ; l'interface reste utilisable sur téléphone.
